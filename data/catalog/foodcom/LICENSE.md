# Food.com / Kaggle: происхождение и условия

В `sample-rows.jsonl.gz` включены первые 5000 исходных строк `recipes.csv` версии 2 датасета **Food.com — Recipes and Reviews**, опубликованного irkaal на Kaggle: https://www.kaggle.com/datasets/irkaal/foodcom-recipes-and-reviews/versions/2 . Это историческая выборка по порядку файла, не случайная и не вручную проверенная.

Загрузчик указывает лицензию CC0: Public Domain: https://creativecommons.org/publicdomain/zero/1.0/ . Эта отметка подтверждена в метаданных Kaggle; независимая проверка прав всех первоначальных авторов Food.com не выполнялась. Сохраняются название источника, версия, исходный RecipeId, автор и дата публикации. Данные этой папки не объявляются текстами Wikibooks и не получают автоматически лицензию CC BY-SA из соседнего LICENSE.md.

Из исходных строк исключено поле Images; изображения не скачивались. Остальные необходимые для воспроизведения поля сохранены, включая пропуски NA и исходные инструкции. SHA-256 полного CSV: `7d564e2fabb9d50d101c4605bddec2612b5e10225778ab015ab68490452788c2`.

Полный локальный CSV и SQLite не включены в Git. Команда `python scripts/build_catalog_db.py --download` загружает закрепленную версию из публичного API Kaggle и строит полный индекс. Ключи Kaggle и данные аккаунта для проверенного скачивания не использовались. Отчет `sample-report.json` относится только к автономной выборке вместе с Wikibooks; полный отчет находится уровнем выше.
