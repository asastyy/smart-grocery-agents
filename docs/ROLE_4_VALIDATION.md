## Ограничения приёмки

Реальный Gemini пока не проверен: нужен локальный пользовательский ключ.
Не подтверждать работу живой LLM по одному `mode=live` в JSON — тест с
подставным транспортом тоже использует этот режим. Нужны успешные реальные
ответы провайдера и рекомендации `Critic [LLM, issue ...]` в истории.
GitHub отклонил публикацию активного workflow: у текущего Personal Access
Token нет права `workflow`. Поэтому шаблон размещён в `docs/github-tests.yml`;
CI пока не активирован и не запускался. Для включения перенести шаблон
в `.github/workflows/tests.yml` через доступ с соответствующим правом. Принятие PR и ревью другим участником ещё требуются.
