## Автоматические проверки

[`github-tests.yml`](github-tests.yml) — шаблон GitHub Actions. Он хранится здесь,
поскольку для публикации требуется право `workflow`. После получения нужных
прав файл переносится в `.github/workflows/tests.yml`. Сейчас проверки
запускаются локально.
