## Final Defense

Для proposal серверное развёртывание не требуется. Для final defense доступная
по ссылке версия даёт 2 балла из 10; курс прямо разрешает отказаться от этих
баллов. Соответствие первоначальному proposal, техническая глубина и ответы на
вопросы будут оцениваться отдельно, поэтому ограничения данных и план следующего
этапа нужно зафиксировать на последнем слайде.

## Блокеры перед выступлением

1. Узнать и вписать два полных ФИО в README и титульный слайд.
2. Подтвердить регистрацию команды в Google-таблице.
3. Перенести готовый сценарий в слайды и дать каждому участнику минимум один.
4. Провести одну репетицию с таймером и live Gemini, не показывая `.env`.
