# Проверка Яндекс Лавки

Проверено 26 ноября 2026 года. Это исследование доступности и данных; работающий программный адаптер Лавки пока не добавлен.

## Что действительно работает

В обычном браузере без входа в Яндекс выбран публичный адрес Канатного цеха НИУ ВШЭ: Санкт-Петербург, 25-я линия Васильевского острова, 6к1. Сайт подтвердил зону доставки. Выполнены поиск риса, поиск молока и открытие карточки риса. До выбора адреса сайт явно показывал демо-каталог.

В карточке риса Prosto подтверждены упаковка 500 г, отображаемая цена 84 ₽, обычная цена 169 ₽, состав и КБЖУ на 100 г. Условия применимости скидки к конкретному заказу не проверены: для консервативной оценки использовать 169 ₽. Для 600 г потребности это 2 упаковки, 338 ₽ и остаток 400 г. Это оценка по карточке, не подтверждённая сумма заказа; доставка и сборка не включены.

У молока «Домик в деревне» на экране 930 мл, но в URL осталось 955 мл. Объём нельзя извлекать из slug. В рисовой выдаче встречаются готовые каши и рекомендации: совпадение поискового слова ещё не означает подходящий ингредиент.

## Что не подтвердилось

Один прямой анонимный запрос к `/api/v1/providers/search/v3/lavka` без адресного контекста вернул HTTP 401; главная страница — 200. Это конкретный результат такого запроса, а не доказательство, что весь каталог требует входа: через сайт адресный поиск работает без входа. Cookies из браузера не извлекались.

Неофициальный MCP не устанавливался и не запускался. Его текущая инструкция требует сессию и местоположение. Поиск и карточки в браузере не доказывают работоспособность MCP. Официальный публичный товарный API этой проверкой не установлен.

## Что учесть при подключении

- В исходном `LavkaClient._trim_product` отсутствие наличия превращается в `True` через значение по умолчанию. Это неприемлемо для наших проверок: отсутствие поля должно давать `unknown`.
- Передавать адресный контекст в каждый поиск, не смешивать предложения разных складов и времени получения.
- Использовать видимые/структурированные поля упаковки; не выводить объём из массы и не разбирать размер из URL.
- Разделять акционную и обычную цену; право на скидку подтверждать отдельно.
- Состав не доказывает отсутствие аллергенов и следов; остаток в штуках также не установлен.
- Для программного эксперимента нужен отдельный локальный профиль/сессия с явно настроенным доступом. Cookies не передавать в чат и GitHub. Запуск стороннего MCP отдельно согласовать после проверки кода; операции корзины и оплаты для поиска не нужны.

## Следующий шаг

Подготовить ограниченный клиент только для поиска и карточки; настроить его локально и повторить те же запросы. После получения исходного адресного JSON добавить нормализацию, контрактные тесты и сравнение упаковок с ВкусВиллом. До этого в приложении нельзя обозначать Лавку как подключённый магазин.
