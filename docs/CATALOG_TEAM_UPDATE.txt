Ребята, максимально расширила текущий каталог из проверенных источников.

Полный локальный индекс теперь содержит 522798 уникальных рецептов с инструкциями: 519096 из полного Food.com v2 и 3702 из Wikibooks. Обработаны все 522517 строк Food.com; отдельно отклонены 2847 неразобранных записей и 574 точных дубля. Полный обход Cookbook дал еще 28 рецептов за пределами прежней категории.

Для такого объема добавила SQLite FTS5 и страницы по 50 результатов: приложение не загружает полмиллиона JSON в память. Проверенные запросы занимают примерно 0,02–0,2 с. В Git лежат код, отчеты, снимок Wikibooks и автономная выборка на 8681 рецепт; полная база около 2,4 ГиБ воспроизводится командой python scripts/build_catalog_db.py --download без ключа Kaggle.

Все 173 теста проходят. Проверены NA в исходных массивах, несовпадающие списки ингредиентов/количеств, дедупликация, поиск, страницы и сохранность базы при ошибке. 100 исходных строк повторно сопоставлены с полным индексом, исходный Golden Test Case сохраняет 1710 руб.

Важно: это большой поисковый каталог, а не 522798 готовых безопасных планов питания. Food.com часто не содержит единиц и имеет несовпадающие массивы количеств; единицы не выдумываются и числа не превращаются в штуки. Подтвержденных аллергенов нет. До автоматического меню и закупки остаются проверка количества/единиц, состава и выбранных основных блюд; очередь из 50 рецептов подготовлена.
